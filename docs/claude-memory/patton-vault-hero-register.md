Reading the vault's `note` / `works` / `weaknesses` fields is **not** using the
vault. Three design passes were rejected while every judgement was quoted
correctly and no screenshot had been opened.

**Why:** a note says *what* worked; the shot shows *how*. The gap between
"Semler is restrained" and its actual device — a state chip on the image, the
count set as the headline, no card containers — cannot be recovered from prose.

**How to apply:**

- Open the images. `vault/shots/<id>/` holds `hero`, `full`, `mobile` and a
  numbered `strip`. **The strip is the scroll sequence and the order is the
  evidence** — compose the frames into one contact sheet and read it as a
  sequence.
- Read `vault/EVIDENCE.md`. It is the synthesis layer with confidence levels,
  and it was ignored for three passes. What it says that changed everything:
  - **C2e — a dark atmospheric ground is NOT a preference.** `ciridae` (3, in)
    and `electrafilmworks` (2, in) are dark; `rmsothebys` (1, **out**) is dark.
    *Darkness does not discriminate.* Building everything dark because it reads
    premium is unsupported.
  - **D5 — both `out` records fail on the same axis:** a strong opening that
    never develops into a page. Polishing a hero for three passes repeats
    exactly the failure Alex rejected.
  - **A1 — one governing event owns the first screen**, high confidence, 6 of 9.
  - **D1 — nothing is known about Alex's colour preferences.** Do not cite the
    vault in support of a colour decision.

**The six automotive `in` records — Rolls-Royce (3), McLaren, Rimac, Hispano
Suiza, Polestar, Oil Stain Lab (3) — all do the same four things:**

1. one frame, full bleed — never a diptych or split;
2. the type set **inside** the frame, not beneath it;
3. tracked, light, large display caps — not tight bold;
4. almost nothing else on screen: a title, one line, one action.

And the RM Sotheby's failure is **not** "type on a picture" — it is a grey CMS
panel on a picture. Type set into an image with no container is what all six
approved references do.
